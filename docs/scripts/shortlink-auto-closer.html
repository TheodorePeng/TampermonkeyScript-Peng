ShortLink Auto Closer

在 ShortLink Studio `/1/` 中转页等待外部协议链接自动触发后，自动关闭当前标签页。

功能介绍

  • 自动关中转页：在 shortlink.studio 的 /1/... 中转页加载时即（document-start）注入关闭逻辑
  • 多次重试机制：默认在 1.2s / 2.5s / 4s 三个时间点尝试调用 window.close()，确保外部协议链接触发后再关闭
  • 路径匹配：仅当 URL 是 /1/<非空后缀> 时才生效，避免误关其它页面
  • 无 UI 静默运行：不渲染任何按钮或面板，零视觉干扰

使用方法

  1. 安装脚本后无需额外设置，配合 ShortLink Direct Opener 使用效果最佳
  2. 点击任意 ShortLink Studio 包装的外部协议链接时，ShortLink Direct Opener 会主动调用系统协议唤起应用
  3. 本脚本在原中转页加载后会在 1.2s / 2.5s / 4s 三个时间点自动调用 window.close()，尝试关闭当前标签页
  4. 由于浏览器安全策略，部分外链唤起需要用户手势，本脚本会自动尽力关闭中转页
本脚本只对 shortlink.studio/1/* 这类"自动跳转"中转页生效，普通的内容页不会被关闭。
只支持 Chromium 系列（Chrome / Edge / Brave 等），因为 window.close() 需要脚本是被"用户主动打开"的页面调用。Firefox 上仅在 Tampermonkey 标签页中能生效，普通网页不行。
