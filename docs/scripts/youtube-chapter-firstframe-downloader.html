YouTube Chapter FirstFrame Downloader

根据 YouTube 视频描述中的时间戳章节，下载每个章节的首帧截图。

基本信息

脚本名称YouTube Chapter First Frame Downloader

安装

安装脚本 查看源码

功能介绍

  • 章节识别：自动解析 YouTube 视频描述中的时间戳章节
  • 首帧捕获：自动跳转到每个章节起点（+2秒偏移），捕获视频首帧画面
  • 批量下载：按章节顺序批量下载所有首帧截图
  • 格式兼容：支持带项目符号的时间戳格式（如 - 0:00 Intro）
  • 文件命名：自动使用章节名和序号命名下载文件

使用方法

  1. 安装脚本后，打开带有章节时间戳的 YouTube 视频页面
  2. 点击 Tampermonkey 菜单中的「Download Chapter First Frames」选项
  3. 脚本会自动依次跳转到每个章节起点，捕获并下载首帧截图
  4. 下载的文件会保存在浏览器默认下载目录中

技术参数

参数值说明
捕获偏移+2 秒章节起点后延迟 2 秒再捕获，避免捕获到黑屏/转场帧
最大文件名长度80 字符超过部分会被截断
等待帧数3 帧跳转后等待渲染完成的帧数
