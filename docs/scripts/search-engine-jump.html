SearchEngineJump

在各搜索引擎之间快捷跳转，支持可视化设置菜单，能更友好的自定义设置，修复百度搜索样式丢失的问题。

安装

安装脚本 查看源码

点击「安装脚本」后，Tampermonkey 会自动弹出安装确认窗口，点击「安装」即可。

功能介绍

  • 搜索引擎快捷跳转：在任意搜索引擎页面，快速切换到其他搜索引擎进行相同关键词的搜索
  • 可视化设置菜单：提供图形化配置界面，方便自定义搜索引擎列表和显示方式
  • 百度搜索样式修复：修复百度搜索页面样式丢失的问题
  • 高度可定制：支持添加、删除、排序搜索引擎，满足个性化需求

使用方法

  1. 安装脚本后，访问任意搜索引擎页面（如 Google、百度、必应等）
  2. 页面会自动出现搜索引擎跳转工具栏
  3. 点击想要切换的搜索引擎图标，即可用当前搜索词在新引擎中搜索
  4. 右键点击工具栏或访问 Tampermonkey 菜单，可打开设置面板进行自定义

依赖说明
