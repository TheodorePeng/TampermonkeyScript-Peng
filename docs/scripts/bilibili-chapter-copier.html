Bilibili Chapter Copier

在 B 站视频章节面板（.bpx-player-viewpoint）header 处添加「复制」按钮，一键复制所有章节的时间范围与名称到剪贴板，便于做笔记或分享。

功能介绍

  • 一键复制章节：在章节面板 header 注入"复制"按钮，点击即可把所有章节"时间 + 标题"复制到剪贴板
  • SPA 路由感知：监听 <title> 元素变化自动重新挂载按钮，B 站 SPA 切换视频时无需刷新
  • MutationObserver 自动注入：监听 DOM 变化，章节面板异步加载后按钮会自动挂上
  • 章节间空行：复制结果相邻章节用空行分隔（time + title 之间），便于粘贴到 Markdown / Obsidian 时形成列表
  • 复制反馈：复制成功 / 未检测到章节信息都有 toast 提示

使用方法

  1. 安装脚本后，打开任意 B 站视频页（带章节的视频）
  2. 页面右侧（或播放器下方）会显示章节面板，header 末尾出现蓝色"复制"按钮
  3. 点击复制，章节列表（"时间范围 + 章节名"）即被复制到剪贴板
  4. 粘贴到 Obsidian / Typora / Notion / Markdown 文件即可
  5. 若该视频没有章节信息，按钮复制会弹 toast 提示"未检测到章节信息"
推荐在长视频（讲座、教程、纪录片）场景下使用；普通短剧 / Vlog 通常没有章节。
