ChatGPT Auto Read Aloud

这是 ChatGPT Audio Controls & Read Aloud 浏览器扩展的轻量 companion userscript。它只跟踪当前页面中新生成的回答，等回答完成后点击该回答已有的朗读按钮，从而启动 ChatGPT 原生 Read Aloud；刷新、切换会话或加载历史消息都不会触发朗读。

功能介绍

  • 自动朗读新回答：默认开启；只处理脚本运行后由当前页面新发起的回答，每条最多触发一次。
  • 原生播放：优先点击 Audio Controls 扩展为目标回答注入的 .cgpt-inline-readaloud，备用路径只使用回答内部直接可见的 ChatGPT 原生朗读按钮，不实现额外 TTS。
  • 新会话安全：等待任务会跨越新 Chat 从临时 WEB: 会话 ID 到正式会话 URL 的切换，不会误取消首轮自动朗读，也不会在首次回答生成时重新登记或干预整个会话。
  • 历史内容安全：初始化、刷新、滚动、侧栏切换和加载旧消息时不会朗读已有回答。
  • 单一悬浮开关：页面只显示一枚半透明 Auto/Speaker 按钮；蓝色为开启，灰色为关闭，等待生成时显示轻微动态状态。
  • 拖拽与位置记忆：按住按钮拖动即可调整位置，刷新和切换会话后继续使用上次位置。
  • 低频菜单设置：Tampermonkey 菜单可隐藏原扩展的空闲 Logo、启用实验性裸左右方向键 seek，或重置悬浮按钮位置。
  • 安全失败：找不到目标朗读按钮时只显示短暂错误状态并输出去敏日志，不会循环点击、打开回答菜单或重置页面音频。

使用方法

  1. 先安装并启用 ChatGPT Audio Controls 扩展，保留它的 Inline Speech Buttons 功能。
  2. 安装本 userscript 后刷新 https://chatgpt.com/；页面左上侧会出现一枚自动朗读按钮。
  3. 首次安装默认开启自动朗读；点击按钮可以快速开关，脚本会记住状态。
  4. 正常发送消息。回答完成并出现该回答的朗读按钮后，脚本会点击一次并验证原生播放器已经启动。
  5. 按住悬浮按钮拖动可以移动位置；鼠标悬浮或键盘 focus 时会显示当前状态。
  6. 打开 Tampermonkey 扩展菜单，可以显示或隐藏 Audio Controls 的空闲 Logo、启用实验性裸左右方向键 seek，或重置按钮位置。

注意事项

  • 升级时会继承 v0.1.4 已保存的自动朗读状态和悬浮位置；没有旧状态时默认开启。
  • v1.0.2 允许同一条新 Chat 回答将一次临时 WEB: 会话 ID 安全升级为正式 ID；其他会话 ID 变化仍会取消待处理任务，避免朗读切换后的历史回答。
  • 隐藏扩展 Logo 只影响 #cgpt-ra-floating-toggle，不会隐藏回答朗读按钮或播放中的进度、暂停、倍速和音量控件。
  • 实验性裸左右方向键默认关闭。其实现依赖上游扩展的 seek 控件行为，当前可能无效，建议保持关闭；v1.0.1 首次运行时会将已有的开启状态一次性重置为关闭，之后仍允许用户手动重新开启。
  • 如果扩展未安装、Inline Speech Buttons 被关闭或 ChatGPT 页面结构改变，自动朗读会安全失败；脚本不会退回到容易干扰页面的菜单模拟方案。
自动朗读开关只控制之后的新回答。关闭时不会停止已经在播放的内容；重新开启时也不会追读页面上已经存在的回答。
本脚本不调用 OpenAI API、不读取或上传对话内容，也不修改 ChatGPT Audio Controls 扩展源码。它只在本地观察生成状态并点击目标回答现有的朗读按钮。
