ChatGPT Auto Read Aloud

在 ChatGPT 页面添加极简半透明 Icon 控制条、快捷键和可选自动朗读。脚本会按当前 ChatGPT 页面实测路径操作：先打开目标回复下方的 More actions / 更多操作，再点击菜单里的 Read aloud / 朗读，随后自动收起菜单；日常运行保持静默，不显示成功或失败提示。

功能介绍

  • 半自动优先：默认不会自动朗读历史回复，点击 Icon 按钮或快捷键后才朗读最后一条 ChatGPT 回复。
  • 轻量 Icon 控制条：控制条默认出现在 ChatGPT 主内容区域左上角，半透明显示，按钮更小，默认不显示文字。
  • 拖拽与位置记忆：按住控制条拖动即可调整位置，刷新或切换对话后保留上次位置。
  • 静默运行：不再显示“成功 / 失败 / 已点击”等 toast 提示，尽量减少对阅读的干扰。
  • 中英文界面兼容：中文界面走“更多操作 → 朗读”，英文界面走“More actions → Read aloud”。
  • 官方朗读路径：优先点击 ChatGPT 菜单项 data-testid="voice-play-turn-action-button"，文案匹配只是备用方案。
  • 快捷键：Alt + Shift + R 朗读最后回复，Alt + Shift + S 停止当前朗读。
  • 可选自动模式：升级到 v0.1.4 后默认关闭；开启后监听新回复完成，再自动触发朗读；每条回复只处理一次，避免长期驻留页面时反复播放。
  • 生成完成判断：自动模式会等待文本稳定、停止回答按钮消失、目标回复出现 More actions / 更多操作按钮。
  • 运行时修复：v0.1.1 修复 Tampermonkey 沙箱下构造 PointerEvent 时的 view 转换错误；v0.1.2 改进 Read aloud 菜单项点击确认，并在触发后收起 More actions 菜单；v0.1.3 移除页面 toast，并加入拖拽位置记忆；v0.1.4 修复拖拽 pointer capture 抢走按钮点击的问题。
  • 停止播放：暂停并重置页面里的 ChatGPT 隐藏 audio 元素，适合停止官方 Read aloud 音频。

使用方法

  1. 安装脚本后打开任意 ChatGPT 对话页，例如 https://chatgpt.com/c/...。
  2. 页面主内容区域左上角会出现三枚小尺寸半透明 Icon 按钮：朗读、停止、自动模式。
  3. 按住控制条拖动即可移动位置，脚本会记住上次放置的位置。
  4. 鼠标悬浮或键盘 focus 到按钮上时，会显示简短文字提示；平时不显示任何状态文字。
  5. 点击朗读 Icon，脚本会定位最后一条 ChatGPT 回复，打开它下方的 More actions / 更多操作菜单，点击 Read aloud / 朗读，并自动收起菜单。
  6. 按 Alt + Shift + R 可以执行同样操作；按 Alt + Shift + S 停止当前朗读。
  7. 需要全自动时，点击自动模式 Icon 切换开关。开启后只处理之后新生成的回复，不会朗读当前页面已有历史回复。

注意事项

  • 自动朗读默认关闭，且 v0.1.4 使用新的设置键，升级后会重置为关闭，避免打开历史对话或页面重渲染时误读旧回复。
  • ChatGPT 前端更新可能改变 DOM 结构，尤其是 conversation-turn、More actions 菜单和 voice-play-turn-action-button。
  • 脚本静默运行；如果没有声音，可能是浏览器音频权限或 ChatGPT 音频状态限制，请先手动点一次 ChatGPT 自带 Read aloud 验证页面是否能正常播放。
推荐日常使用半自动模式：需要听最后一条回复时按 Alt + Shift + R。自动模式适合你明确希望每条新回复都自动朗读的场景。
本脚本依赖 ChatGPT 网页 DOM，不调用 OpenAI API，也不修改对话内容。若 ChatGPT 页面改版导致按钮找不到，需要更新选择器。
