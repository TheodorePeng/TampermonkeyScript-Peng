Doubao Timeline Markdown Exporter

在豆包（Bilibili 视频解读页）右下角提供悬浮复制按钮，把豆包生成的高亮时间线节点一键复制为 Markdown bullets，便于做笔记或导出到 Obsidian。

功能介绍

  • 悬浮圆形按钮：在豆包 Bilibili 解读页右下角添加黑色毛玻璃圆形按钮，hover 显示「复制 Markdown」提示
  • 一键复制 Markdown bullets：自动提取豆包生成的时间线高亮（youtube-share-page-highlight-item-*），按"时间 + 标题"格式化为 Markdown 列表
  • DOM 优先 + 文本回退：先从 [data-testid^="youtube-share-page-highlight-item-"] DOM 结构提取；DOM 缺失时回退到正文文本扫描带时间戳的行（MM:SS 或 HH:MM:SS）
  • 结构化产出：每个 group 一个一级 bullet，子节点缩进为二级 bullet，groups 之间用空行分隔
  • 状态机反馈：按钮有 idle / loading / success 三种状态，配合 toast 提示，支持 Promise / async/await 全异步
  • MutationObserver 自动重挂：监听 DOM 与 popstate 事件，豆包 SPA 路由切换后按钮自动重新挂载
  • 去重 + 净化：相同"时间 + 标题"自动去重，文本中的多余空白被合并（normalize）

使用方法

  1. 安装脚本后，打开任意豆包 Bilibili 视频解读页（https://www.doubao.com/summary/bilibili/<id>）
  2. 页面右下角出现一颗黑色圆形按钮（带悬浮提示"复制 Markdown"）
  3. 点击按钮或通过 Tampermonkey 菜单的「Copy Doubao Timeline Markdown」触发
  4. 脚本会自动等待时间线 DOM 出现（最多 15s），提取后复制 Markdown 到剪贴板
  5. 按钮变为绿色（success 状态）约 1.6s，伴随右上角 toast 提示"已复制为 Markdown"
  6. 将内容粘贴到 Obsidian / Typora / Notion 等编辑器即可

豆包前端改版可能导致 DOM 选择器失效。如果按钮存在但点击后提示"未发现时间线节点"，请反馈到仓库 Issue，作者会跟进修复选择器。
