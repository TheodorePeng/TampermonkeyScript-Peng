Move Subtitle to Floating Window

现代化的字幕悬浮窗口工具，支持拖拽、调整大小、折叠和透明度控制，适用于 YouTube 和哔哩哔哩。

功能介绍

  • 字幕悬浮化：将视频内置字幕提取到独立的浮动窗口中显示
  • 自由拖拽：可以随意拖动字幕窗口到屏幕任意位置
  • 调整大小：支持拖动边框调整字幕窗口大小
  • 折叠/展开：支持将字幕窗口折叠为小型按钮，需要时一键展开
  • 透明度控制：可调节字幕窗口的背景透明度
  • 双站支持：同时支持 YouTube 和哔哩哔哩两大视频网站

使用方法

  1. 安装脚本后，打开 YouTube 或 Bilibili 视频页面
  2. 页面会出现一个悬浮控制按钮
  3. 点击按钮即可将视频字幕提取到浮动窗口
  4. 拖动窗口调整位置，拖动边框调整大小
  5. 点击折叠按钮可将字幕收为小型控制条
