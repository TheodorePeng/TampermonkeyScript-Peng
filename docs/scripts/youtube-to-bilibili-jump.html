YouTube to Bilibili Jump

在 YouTube 左上角添加极小半透明按钮，左键直接跳转 B 站第一个搜索结果，右键打开面板（搜索词可编辑）。

安装脚本 查看源码

功能介绍

  • 一键跳转 B 站：在 YouTube 视频页添加极小按钮，一键跳转到哔哩哔哩搜索相同内容
  • 自动搜索匹配：自动提取 YouTube 视频标题作为搜索词
  • 可编辑搜索词：右键点击按钮可打开面板，自由编辑搜索关键词
  • 极简设计：按钮极小且半透明，不影响正常观看体验

使用方法

  1. 安装脚本后，打开任意 YouTube 视频页面
  2. 页面左上角会出现一个极小的半透明按钮
  3. 左键点击：直接在新标签页打开哔哩哔哩，搜索该视频标题
  4. 右键点击：弹出面板，可以编辑搜索词后再跳转
非常适合在 YouTube 上看到有趣内容后，快速去 B 站找弹幕版或中文翻译版观看。
