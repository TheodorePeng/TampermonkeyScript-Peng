Duxiu Book Enhancer（红太狼的平底锅）

读秀 / 超星图书增强：在搜索结果页与详情页直接显示图书 SSID / DX 号，并提供"部分阅读"、"试读"、"存货查询"、"返回 BookDetail"等快捷按钮。

功能介绍

  • SSID / DX 直显：在读秀搜索结果页与详情页直接显示图书唯一编码 SS 号（无 SSID 则显示 DX 号）
  • 存货查询：详情页增加"存货查询"按钮，跳转到国家图书馆藏量查询接口
  • 部分阅读 / 试读：详情页增加"部分阅读"入口（试读页再增加"试读"按钮一键打开）
  • 一键下载四联图：在试读页 / 包库在线阅读页增加"一键下载"按钮，把封面 / 书名 / 版权 / 封底四张 PDG 图一键触发下载
  • 返回按钮：试读页加"返回 BookDetail"按钮，不用浏览器后退一键回到详情页
  • 显示 SSID（高级搜索 / 包库）：读秀"高级搜索"页与"包库搜索"页增加"显示 SS / 显示 SSID"按钮，一键注入所有结果的 SSID
  • 类型切换：藏馆页可一键切换"纸质藏馆"与"存货查询"

使用方法

  1. 安装脚本后，访问读秀 / 深圳文献港 / 全国图书馆参考联盟的搜索页或详情页
  2. 搜索结果页：每本书的封面图片附近自动注入 SSID / DX 号文本
  3. 详情页：SSID 显示在封面图片下方，下方按钮区出现「部分阅读」「存货查询」两个新按钮
  4. 试读页：左侧 PDG 列表底部出现「一键下载」链接，可一键触发下载
  5. 「包库在线阅读」页同样支持一键下载四张 PDG 图
如果 SS 号 8 位则直接显示，超过 8 位则改用 DX 号。这是读秀官方历史遗留编码规则。
