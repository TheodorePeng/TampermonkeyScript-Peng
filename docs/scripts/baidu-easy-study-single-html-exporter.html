Baidu Easy Study Single HTML Exporter

将百度网盘「简单学习」页面导出为单个离线 HTML 文件：自动内联 CSS / JS / 字体 / 图片资源，附带本地顶栏与离线交互脚本，可直接在本地打开使用。

功能介绍

  • 单文件离线导出：把当前简单学习页（含 iframe 子页）的 DOM、样式、字体、图片全部内联到一个 .html 文件
  • 本地顶栏：导出后的 HTML 顶部自带"导航 / 分享 / 导出 / 反馈"四个本地按钮，可继续操作
  • iframe 通信：外层页与内层简化学习 iframe 通过 postMessage 协议通信，兼容跨域场景
  • 运行时净化：剥离 chrome-extension / tailwindcss 运行时 / MathJax-script 等内联脚本，避免离线打开报错
  • 资源 inline：把 url(...) 形式的远程资源（字体、图片）转成 data: URI，确保离线可用
  • 悬浮按钮：右下角浮动 ⇩ 按钮，hover 提示"导出单 HTML"，点击立即触发导出
  • 注册菜单命令：Tampermonkey 菜单命令"导出单 HTML"也可以触发同样的逻辑

使用方法

  1. 安装脚本后，打开百度网盘"简单学习"详情页（外层或带 iframe 的 inner 页均可）
  2. 页面右下角会出现一颗悬浮 ⇩ 按钮
  3. 点击按钮或通过 Tampermonkey 菜单运行"导出单 HTML"
  4. 浏览器自动下载一个 <标题>.html 文件，文件名经过非法字符清洗
  5. 下载完毕后离线打开，可以看到顶部带本地顶栏、所有样式 / 字体 / 图片都已内嵌

技术特性

特性说明
iframe 通信通过 postMessage 在外层与内层 iframe 之间传递快照请求 / 响应
资源下载使用 GM_xmlhttpRequest 跨域抓取 CSS / JS / 图片，二进制资源转 data: URI
CSS 内联同步解析并替换所有 url(...) 为 data URI，确保离线字体可用
DOM 净化移除 tailwindcss runtime / MathJax-script / extension scripts 等在线依赖
本地顶栏注入 navigation / share / export / feedback 四个按钮的本地壳 JS
移动端会自动把按钮尺寸缩小、内边距调小，placeholder 文案在 < 840px 时被隐藏。
