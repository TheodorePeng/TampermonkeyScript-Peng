BaiduPan FloatingWindow

将百度网盘视频播放器和播放列表创建为可拖动、可调整大小的浮动窗口。优化后窗口位置和大小不再受浏览器窗口缩放影响。

功能介绍

  • 播放器浮动化：将百度网盘视频播放器转为可自由拖动的浮动窗口
  • 播放列表浮动化：播放列表同样可以独立浮动，方便同时查看
  • 自由调整大小：支持拖动边框调整窗口大小
  • 位置记忆：窗口位置会被记忆，刷新页面后自动恢复
  • 不受缩放影响：优化后浏览器窗口缩放不会影响浮动窗口的位置比例

使用方法

  1. 安装脚本后，打开百度网盘视频播放页面
  2. 页面左上角会出现一个蓝色圆形切换按钮
  3. 点击按钮即可将视频播放器转为浮动窗口模式
  4. 拖动窗口标题栏可移动位置，拖动边框可调整大小
  5. 再次点击按钮可切换回正常模式
如果你需要更强大的双悬浮窗功能（同时显示视频窗和资料窗），可以查看同系列的 BaiduPan FloatingWindows Pro。
