TampermonkeyScript-Peng

本仓库是 TheodorePeng 个人常用的 Tampermonkey / Greasemonkey 用户脚本合集，用于提升日常网页浏览、学习笔记和内容获取的效率。

所有脚本均为开源项目，遵循 MIT License。你可以按需安装使用。

快速开始

  1. 安装扩展：先安装 Tampermonkey（Chrome / Edge / Safari / Firefox 均可）
  2. 选择脚本：在下方找到你需要的脚本，点击进入详情页
  3. 一键安装：在详情页点击「安装脚本」按钮，Tampermonkey 会自动弹出安装窗口
  4. 开始使用：访问对应网站，脚本即会自动生效
提示：安装后 Tampermonkey 默认会自动检查更新。你也可以在 Tampermonkey 面板中手动点击「检查更新」。
