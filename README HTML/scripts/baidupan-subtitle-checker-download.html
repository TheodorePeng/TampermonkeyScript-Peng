功能介绍

  • 网络请求监听：自动监听百度网盘页面发出的网络请求
  • 字幕检测：检测请求中是否包含 netdisk-subtitle 关键字
  • 自动下载：检测到字幕后自动触发下载
  • 下载状态提示：在页面左下角显示绿色下载图标，表示字幕已下载
  • 防重复下载：同一会话中已下载的字幕不会重复下载

使用方法

  1. 安装脚本后，打开百度网盘任意页面
  2. 当页面加载包含字幕的视频时，脚本会自动监听网络请求
  3. 检测到字幕文件后，会自动下载到浏览器默认下载目录
  4. 页面左下角会显示绿色图标，表示字幕已成功下载
本脚本与 BaiduPan SubtitlePlayer 配合使用效果更佳：先用本脚本自动下载字幕，再用 SubtitlePlayer 加载并同步播放。
