GetShareNote Notion Exporter

导出 GET 分享笔记为 Notion 友好的 Markdown，支持文字记录、智能总结、sprouts、子笔记的复制与下载。

功能介绍

  • 文字记录导出：导出语音笔记的文字转录内容
  • 智能总结导出：导出 AI 生成的内容总结
  • Sprouts 导出：导出灵感速记（sprouts）内容
  • 子笔记导出：支持导出附带的子笔记内容
  • Notion 友好格式：Markdown 格式专门针对 Notion 的导入优化
  • 复制与下载：支持一键复制到剪贴板或下载为 .md 文件
  • 完整 UI 面板：提供美观的导出控制面板，可选择导出内容类型

使用方法

  1. 安装脚本后，打开 GET 分享笔记页面（biji.com/note/share_note/*）
  2. 页面会出现浮动导出按钮
  3. 点击按钮打开导出面板
  4. 在面板中选择需要导出的内容类型（文字记录/智能总结/sprouts/子笔记）
  5. 点击「复制」复制到剪贴板，或「下载」保存为 Markdown 文件
  6. 粘贴到 Notion 中即可

内容类型说明
