ShortLink Direct Opener

直接打开 ShortLink Studio 包装的外部协议链接，并自动关闭 ShortLink 中转页。支持白名单协议配置和黑名单安全过滤。

功能介绍

  • 协议直开：直接打开被 ShortLink Studio 包装的外部协议链接，无需手动点击中转页
  • 自动关闭中转页：跳转成功后自动关闭 ShortLink 中转页面
  • 白名单机制：仅允许打开预设的安全协议，防止恶意链接
  • 黑名单过滤：支持配置黑名单，过滤不安全的协议
  • 多协议支持：支持 obsidian、notion、marginnote、slack、zoom、figma、zotero 等常用协议

使用方法

  1. 安装脚本后，打开包含 ShortLink 链接的页面（如 Notion 分享页）
  2. 当页面中包含外部协议链接时，脚本会自动识别
  3. 如果链接协议在白名单中，脚本会自动触发打开对应应用
  4. 跳转成功后，ShortLink 中转页会自动关闭

默认支持的协议

协议对应应用

如果你使用的应用协议不在默认列表中，可以编辑脚本内的 DEFAULT_ALLOWED_SCHEMES 数组自行添加。
出于安全考虑，脚本默认只允许白名单中的协议。请不要随意添加不熟悉的协议，以免打开恶意应用。
