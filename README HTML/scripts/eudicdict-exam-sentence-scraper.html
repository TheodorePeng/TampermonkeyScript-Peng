EudicDict Exam Sentence Scraper

自动爬取欧路词典词条页「大学英语四级六级考研真题库」中的考研真题句子，输出标准 Markdown 格式。

安装

安装脚本 查看源码

功能介绍

  • 自动爬取真题：自动点击「考研」标签 →「查看更多」，加载全部考研真题句子
  • 标准 Markdown 输出：生成的 Markdown 包含 e.g. 前缀、中文翻译、出处
  • 每日英语听力链接：每句附带每日英语听力 App 的跳转链接
  • 一键复制：爬取完成后可一键复制全部内容到剪贴板
  • 进度显示：爬取过程中实时显示加载进度

使用方法

  1. 安装脚本后，打开欧路词典任意英文词条页面
  2. 点击 Tampermonkey 菜单中的「爬取考研真题句子」
  3. 脚本会自动展开真题库，逐页加载全部考研例句
  4. 加载完成后弹出结果面板，显示所有爬取的句子
  5. 点击「复制」即可将标准 Markdown 格式的内容复制到剪贴板

输出格式示例

e.g. This is a sample sentence from the exam.
    这是考研真题中的例句中文翻译。
    —— 来源：2020年考研英语一阅读理解
