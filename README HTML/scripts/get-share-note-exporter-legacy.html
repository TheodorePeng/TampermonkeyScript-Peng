GetShareNote Exporter (Legacy)

GET 分享笔记导出的早期版本，功能相对简单，支持基础的文字记录和子笔记导出。

安装

安装脚本 查看源码

功能介绍

  • 文字记录导出：导出语音笔记的完整文字转录
  • 子笔记导出：支持导出附带的子笔记
  • Notion 友好格式：输出 Markdown 格式，适合导入 Notion
  • 页面内预览：导出前可在页面内预览 Markdown 内容
  • 复制与下载：支持复制到剪贴板或下载文件

使用方法

  1. 安装脚本后，打开 GET 分享笔记页面
  2. 点击 Tampermonkey 菜单中的导出选项
  3. 在弹出面板中查看导出内容
  4. 点击「复制」或「下载」获取 Markdown 内容
这是早期版本（v0.1.0），功能相对基础。如需完整功能（智能总结、sprouts、更完善的 UI 面板等），建议使用新版 GetShareNote Notion Exporter v0.2.0。
