EudicTing MD Exporter

导出每日英语听力（欧路词典）文章句子为 Markdown 格式，支持逐句来源链接，适配 Obsidian / Eudic 笔记。

功能介绍

  • Markdown 导出：将每日英语听力的文章内容导出为标准 Markdown 格式
  • 逐句来源链接：每句话都附带来源链接，方便回溯原文
  • Obsidian 适配：导出格式兼容 Obsidian 笔记软件的语法规范
  • Eudic 适配：同样兼容欧路词典笔记系统的导入格式
  • 来源标签自定义：支持自定义文章来源标签
  • 元数据控制：可选择是否包含标题、日期等元数据
  • 空白行设置：支持调整句子间的空白行数

使用方法

  1. 安装脚本后，打开欧路词典每日英语听力网页版
  2. 打开任意文章页面
  3. 点击 Tampermonkey 菜单中的导出选项，或页面上的导出按钮
  4. 在弹出面板中选择导出选项（元数据、来源标签、空白行等）
  5. 点击「复制」将内容复制到剪贴板，或「下载」保存为 .md 文件
  6. 粘贴到 Obsidian 或 Eudic 笔记中即可
