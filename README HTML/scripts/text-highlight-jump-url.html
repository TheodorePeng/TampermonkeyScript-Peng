TextHighlightJumpURL

选中文本后自动生成带 Text Fragments 的高亮链接，输出 Markdown 格式，支持自定义快捷键触发。

基本信息

脚本名称HighlightJump URL
版本1.9
作者TheodorePeng
适用站点任意网页（*://*/*）

安装

安装脚本 查看源码

功能介绍

  • Text Fragments 链接生成：选中文本后，自动生成带有高亮参数的 URL，让别人打开链接时直接定位到你选中的文字
  • Markdown 格式输出：生成的链接自动格式化为 Markdown，方便粘贴到笔记软件中
  • 自定义快捷键：支持自定义触发快捷键，可跨平台配置（Mac/Windows）
  • 一键复制：生成后自动复制到剪贴板

使用方法

  1. 安装脚本后，在任意网页上选中想要分享的文本段落
  2. 按下设定的快捷键（默认通常为组合键）
  3. 脚本会自动生成带高亮参数的链接，并复制到剪贴板
  4. 将链接分享给他人，对方打开后浏览器会自动滚动并高亮对应文本
兼容性：Text Fragments 功能需要现代浏览器支持（Chrome 80+、Edge 80+）。不支持的老浏览器仍可正常打开链接，只是不会自动高亮。
